A tiny stack virtual machine in one small TypeScript file: it runs every program of a set (32-bit wrapping integers, a 256-value stack, 256 words of memory, branches, calls, input and output, ten traps with their own exit codes, a step limit and an output limit) and writes exactly the bytes and exit code each program ends with.

## Run it

```sh
node main.ts
```
